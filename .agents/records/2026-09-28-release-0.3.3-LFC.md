## 本轮踩坑（均为环境级，非代码问题）

1. **构建机 `python` 全坏**：PATH 上的 `python` 是 Microsoft Store 占位 stub（任何调用无输出退出码 49）；`py` launcher 指向不存在的 `F:\Python\python.exe`。用 uv 托管的 CPython 3.12（`C:\Users\AlchemistCxC\.local\bin\python3.12.exe`）替代，并把 uv python 目录前置到 PATH，使 bun 子进程（`pack:portable` 内 `python scripts/pack_release.py`）也解析到真解释器。第二轮构建就是死在这一点上：Rust 全链已成功，仅打包步 exit 49。
2. **bun 退出期崩溃（第一轮）**：vite build 成功后 bun 进程退出时触发 libuv 断言 `UV_HANDLE_CLOSING`（src\win\async.c:94），脚本整体 exit 9。仓内无既有记录，属偶发，重试即过。
3. **发行 `.sha256` 附件带 CRLF**：`gh release download` 下来的 `pylon-0.3.3-LFC-win64.zip.sha256` 行尾为 CRLF，`sha256sum -c` 会把 `\r` 并进文件名而报 FAILED open or read。验收时 `tr -d '\r'` 后校验即过。发布链可考虑落盘 LF（留给后续，不阻塞）。
4. **幻影改动阻断切分支**：收尾切 `main` 时被 `src-tauri/Cargo.toml` 的 M 状态拦下，但 index blob / HEAD blob / 工作树三方 `cmp` 字节一致（构建期 touch 导致 stat 缓存脏）。`git restore` 恢复（内容不变，无在途工作损失）后正常切换。
