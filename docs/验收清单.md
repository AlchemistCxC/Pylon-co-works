### 1.2 自动命令

## 2. 验收层级

### L0：源码存在

只证明文件、符号、command 注册或 UI 入口存在。

### L1：纯函数/结构测试

只证明 adapter、状态机、源码结构或静态断言符合测试；不能证明 React 浏览器行为、Tauri IPC、子进程或 ACP wire 行为。

### L2：构建/静态检查

- `npm run build`：TypeScript 和 bundling。
- `cargo check`：Rust 类型与借用检查。

不证明运行时。

### L3：浏览器 UI

验证 DOM、键盘、响应式、视觉、localStorage round-trip；浏览器 mock 不证明 Tauri command。

### L4：Tauri runtime

验证真实 `invoke`、窗口行为、文件系统、pet、Workspace、RuntimeLogHub。

### L5：ACP / Agent runtime

验证真实子进程、JSON-RPC、streaming、cancel、timeout、crash、generation、Peri response。

功能只有达到其所依赖的最高层，才能标“已验收”。

## 5. Session / Chat / ACP 验收

### 5.1 正常会话

- [ ] 新建本地 session，记录前端 `Session.id/source/periId` 三者。
- [ ] 抓到 ACP `initialize` 请求和 response。
- [ ] 抓到 `session/new` 请求，确认 `cwd`、`mcpServers`。
- [ ] 确认 response 有合法非空 `sessionId`、modes、configOptions。
- [ ] 发送首轮非 slash prompt，确认 persona/sessionPrompt 只拼接一次。
- [ ] 记录顺序：`peri:user → peri:update* → peri:done`。
- [ ] Agent text、reasoning、tool、usage 正确显示。
- [ ] 第二轮 prompt 不重复拼接 persona。

### 5.2 多会话

- [ ] A 生成中切到 B，A 的 update 继续写入 A，不污染 B。
- [ ] B 可独立发送，不被 A 的 source prompt lock 阻塞。
- [ ] A/B 的 mode、model、usage、generating、消息缓存独立。
- [ ] 删除 A 后，迟到的 A 事件被丢弃。

### 5.3 Replay

- [ ] 有历史 session 的 `session/load` 在 response 前产生 `_meta.periReplay=true` update。
- [ ] replay user chunk 只生成一份 user message。
- [ ] replay tool start/update 正确配对，缺失/重复 ID 不崩溃。
- [ ] 空 replay 不覆盖已有本地缓存。
- [ ] A/B/A 快速切换时旧 load generation 不覆盖当前页面。
- [ ] replay 完成后不残留 live spinner/generating。

### 5.4 Cancel / timeout / error

- [ ] 点击停止时只发送一次 `session/cancel`。
- [ ] cancel 成功后 UI 进入 cancelled 终态，不显示普通 error。
- [ ] command 失败时停止按钮恢复，可再次操作。
- [ ] 300 秒 timeout 路径发送 cancel 并等待 settle。
- [ ] settle 失败时本地 mapping 删除并尝试 close，有日志证据。
- [ ] ACP connection closed、非法 stopReason、JSON-RPC error 都显示可见错误。

## 16. 完成定义

全部满足后才能宣称项目“已验收”：

1. 前端测试没有被允许吞掉的失败。
2. Rust test harness 能真实运行。
3. Session、Agent、Config、Workspace、Logs、Pet 均有 Tauri runtime 证据。
4. ACP 主链、replay、cancel、timeout、crash、generation 均有抓包或等价硬日志。
5. mock/占位/未接入功能仍被明确标注，没有被文档包装成已完成。
