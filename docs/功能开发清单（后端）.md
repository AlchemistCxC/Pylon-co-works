## 1. 后端架构事实

- Tauri v2 command 层位于 `src-tauri/src/lib.rs`。
- ACP 子进程 JSON-RPC 客户端位于 `src-tauri/src/acp.rs`。
- Agent 配置位于 `src-tauri/src/agent_config.rs`，运行时从 YAML 加载。
- Agent 生命周期与 generation 辅助逻辑位于 `src-tauri/src/agent_runtime.rs`。
- Workspace 文件访问位于 `src-tauri/src/workspace.rs`。
- RuntimeLogHub 位于 `src-tauri/src/runtime_log.rs`。
- MCP 校验/序列化位于 `src-tauri/src/mcp.rs`。
- 宠物运行时适配位于 `src-tauri/src/pet.rs`，成长核心位于 `src-tauri/pet-core/src/lib.rs`。
- 当前 transport 只实现 `subprocess`，通过 stdin/stdout 传输 JSON-RPC；其他 transport 会返回 unsupported transport。

## 3. 关键后端不变量

### 3.1 三层会话映射

- Pylon `source` 是 `AppState.sessions` 的 map key。
- `SessionInfo.peri_id` 是远端 ACP `sessionId`。
- 每个 `SessionInfo` 还带 `generation`。
- 事件必须同时匹配 source 映射、Peri ID 和 client generation；旧客户端事件被拒绝。

### 3.2 ACP notification 路由

`start_notification_dispatcher`：

1. 只消费当前 ACP client generation。
2. `session/update` 必须有 object params、`sessionId`、`update`。
3. 通过 `peri_id` 找到 Pylon source。
4. 只接受匹配当前 generation 的 session。
5. `user_message_chunk` 仅在 `_meta.periReplay=true` 时转为 `peri:user`，避免 live prompt 的 user 消息重复。
6. 其余 update 添加 `source` 后发出 `peri:update`。
7. ACP 子进程 stdout 关闭时发出 `peri:agent-status` crashed。

### 3.3 Prompt 生命周期

- 每个 source 有独立 prompt lock，同一 source 不允许并发 prompt。
- 创建/替换 session 使用 creation lock。
- prompt 超时后发送 `session/cancel`，等待最终 response；仍未收敛时删除匹配的本地映射并尝试 `session/close`。
- generation 不匹配时拒绝旧结果，并清理仍匹配的旧 session。
- `cancel_prompt` 本身是 fire-and-forget notification；最终 cancelled 语义由 ACP response/event 收敛。

### 3.4 安全边界

- Workspace 相对路径拒绝 traversal、绝对盘符路径、root 外路径和越界 symlink。
- Workspace 默认隐藏 `.git`、`node_modules`、`dist`、`build`、`target`、`.next`、`.vite`、`coverage`。
- Workspace 目录有最大条目数限制，文本预览有默认/最大字节限制，NUL/非 UTF-8 视为 binary。
- RuntimeLogHub 对 token、secret、authorization、prompt、persona、content、raw input/output、attachment、env 等字段脱敏；消息含敏感 payload marker 时整体替换为 `[REDACTED]`。
- MCP 仅允许 `stdio`、`sse`、`streamable-http`、`http`；HTTP URL 仅允许 http/https；服务、args、env、headers 有数量限制。
- Agent `exe`、args、cwd、env 来自 agents YAML；当前 command 只允许本地 Tauri 调用边界，未提供远程 HTTP 管理 API。

## 5. 当前不应从旧文档继承的结论

- “Rust `cargo test --lib` 已通过”不真实：本轮实际编译成功后，运行阶段以 `0xc0000139 STATUS_ENTRYPOINT_NOT_FOUND` 退出，exit code 127。
- “真实 Tauri + Peri 已验收”不真实：当前只有静态源码与纯函数/前端结构测试证据。
- “MCP 已完成”只能表示输入校验和 ACP 序列化已有代码；storage/merge/真实 Peri 传输仍未验收。
- “Workspace/Logs 已完成”只能表示 command 与前端 adapter 已接线；真实目录和运行日志仍未验收。
- “Agent lifecycle 已完成”只能表示实现和纯状态测试存在；真实进程行为仍未验收。
