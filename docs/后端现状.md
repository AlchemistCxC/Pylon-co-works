## 3. 架构与模块

```
src-tauri/src/
├── lib.rs (4,400)   主状态机 + 63 命令 + dispatcher + 自动重连 + 权限/注入接线
├── acp.rs  (1,650)  ACP 客户端：子进程/锁外 RPC/pending 16 分片/超时/崩溃检测
├── gateway/         平台适配器层
│   ├── mod.rs       GatewayCore（适配器注册表 + 配置 RwLock 热重载 + ingest/deliver）
│   ├── route.rs     EntityBinding 路由表 + inject 配置解析
│   ├── truncate.rs  长回复分段器（fence 保留/指示器/自然切点）
│   └── qq/          QQ 适配器（ws 事件循环/auth token/dedup/events/send 发送）
├── prism.rs (557)   Prism loopback 客户端（loopback 白名单/禁重定向/错误分类）
├── git.rs   (334)   Git 只读（超时杀进程/quotePath=false/containment）
├── runtime_log.rs   日志中心（ring 2000/广播 256/递归脱敏）
├── agent_config.rs  agents.yaml 解析（结构化 acp 参数/协议字典外置）
├── mcp.rs / workspace.rs / error.rs / agent_runtime.rs / runtime.rs
├── pet.rs + pet-core/  宠物适配层 + 独立状态机 crate（lib.rs + lines.rs）
```

**关键机制**：
- per-agent 隔离运行时（`AgentRuntimeManager`），generation 代际路由防串扰
- 锁外 RPC（prepare_rpc → complete_rpc），Peri 卡顿不阻塞其他命令
- 时间戳驱动（宠物需求衰减/延迟行为零后台任务）
- 感知层：工具分类字典 + rawInput 脱敏提取（secret 绝不下沉）
