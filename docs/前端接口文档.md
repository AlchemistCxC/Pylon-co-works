# Pylon 前端接口文档（Tauri v2）

> 本文档描述后端（`src-tauri`）对前端（`src/`）暴露的完整 invoke 命令面与事件面。
> 事实源：`src-tauri/src/lib.rs` 的 `generate_handler!` 实注册 + 事件 emit 点（2026-08-01 对齐 main@0422fd6）。
> 若与源码冲突，以源码为准。

## 1. 调用约定

- **invoke**：`window.__TAURI__.core.invoke('命令名', { 参数: 值, ... })`（Tauri v2，`withGlobalTauri: true`）
- **命名**：命令/参数/字段一律 camelCase（Rust 侧 `snake_case` 参数由 Tauri 自动映射为 camelCase）
- **错误**：失败返回 `{ code: string, message: string }`（见 §3 错误码全表）；成功按各命令返回类型
- **可选参数**：文档标 `?` 的字段传 `null` 或省略均可

## 2. 命令面

### 2.1 会话与消息（Session/Prompt）

#### `new_session`
创建新 ACP 会话（同一 `source` 已存在则替换旧会话并 close）。
| 参数 | 类型 | 说明 |
|:--|:--|:--|
| source | string | 会话路由 key（`local` 或平台 key 如 `qq:group:123`） |
| persona | string | 人设（空串允许） |
| cwd? | string \| null | 工作目录，缺省用 agent 配置 cwd |
| mcp_servers? | McpServerConfig[] \| null | MCP 配置（见 §4.1） |

返回：agent 的完整 session/new 响应（含 `sessionId`、`modes`、`configOptions`）。
错误：`session_not_found` 无；上限 100 会话 → `protocol_error`。

#### `send_message`
发送消息（自动建会话；首条且 persona 非空且不以 `/` 开头时，prompt 前拼 persona）。
| 参数 | 类型 | 说明 |
|:--|:--|:--|
| source | string | 会话 key |
| content | string | 消息文本 |
| persona | string | 人设（首条拼接用） |
| session_prompt? | string \| null | 覆盖 persona 的会话级 prompt |
| attachments? | string[] \| null | 附件文件路径（≤8 个、≤10MB/个，图片/文本/未知按 UTF-8） |
| mcp_servers? | McpServerConfig[] \| null | 仅新会话创建时生效 |

返回：`peri_id`（string）。
注：B11 注入开启时，发送前调 Prism `/inject`，context 前置拼进 prompt；`peri:user` 事件带 `injectActivated`。

#### `set_mode(source, mode)` → void
切换会话模式（Peri `session/set_mode`）。

#### `set_config_option(source, key, value)` → object
设置会话配置项。`key="model"` 时按 agent 配置分叉：`set_model_api: true`（Hermes 系）走 `session/set_model`，否则 `set_config_option("model")`。
返回：agent 响应（含 `configOptions` 时更新会话）。

#### `close_session(source)` → void
关闭会话：先 cancel 在途 prompt，再 `session/close`（-32601 降级本地清理）；应答该会话挂起的权限请求为 Cancelled。

#### `cancel_prompt(source)` → void
取消在途 prompt（fire-and-forget + settle 30s）；应答挂起权限请求为 Cancelled。

#### `load_sessions()` → SessionRow[]
当前 active agent 的会话列表（见 §4.3 数据结构）。

#### `session_inspector()` → object
全局聚合（B2 完整版，见 §4.4）。

#### `load_persisted_session(source, peri_id, cwd?, mcp_servers?)` → object
重放历史会话（session/load + replay 事件经 `peri:user`/`peri:update` 回放，带 `replay: true` 标记）。
返回：session/load 响应。

#### `list_persisted_sessions()` → object
`session/list` 响应（persisted 会话清单）。

#### `export_session(peri_id, format, output_path)` → void
导出会话到文件。`format`: `"markdown" | "json"`；`output_path`: 不存在路径（拒绝覆盖）；内容经 secret 脱敏（rawInput/rawOutput/prompt/persona/headers/env/authorization/token/secret）。

### 2.2 Agent 注册与生命周期

#### `list_agents()` → AgentSummary[]
| 字段 | 类型 | 说明 |
|:--|:--|:--|
| id | string | registry key |
| name | string | 展示名 |
| transport | string | 目前恒为 `"subprocess"` |
| available | boolean | 是 active 且状态 connected |
| active | boolean | 当前 active |
| cwd | string \| null | 工作目录 |

#### `switch_agent(name)` → void
切换 active agent（目标懒启动；旧 agent dispatcher 先 abort 再 kill，状态置 Disconnected）。

#### `reconnect_agent()` → void
重连当前 active agent（跨 agent/全新进程语义，清空会话映射）。

#### `agent_status()` → object
当前 active agent 状态（见 §4.5）。

#### `reload_agents(config_path?)` → void
热重载 agents 配置（`PYLON_AGENTS_CONFIG` 或内置 agents.yaml）；校验失败拒绝；不允许移除 active agent。

#### `validate_agents()` → object
`{ valid: true, defaultAgentId: string, agents: AgentSummary[] }`（不启动任何进程）。

### 2.3 工作区（只读）

#### `get_workspace_root(source)` → WorkspaceRoot
source 会话 cwd 的 root 状态（`{source, path, exists, readable}`）。

#### `list_workspace_entries(source, relative_path?, include_hidden?)` → WorkspaceEntry[]
`relative_path` 缺省 `"."`；忽略 `.git/node_modules/dist/build/target/.next/.vite/coverage`；目录 1000 条上限；symlink 越界跳过。
字段：`name, relative_path, kind(directory|file|symlink|other), size, modified_at?, hidden, expandable`。

#### `read_workspace_text(source, relative_path, max_bytes?)` → WorkspaceTextPreview
`{relative_path, content, bytes_read, total_bytes, truncated, encoding}`；默认 256KB / 最大 1MB；NUL/非 UTF-8 → `workspace_error`。
路径安全：拒绝绝对路径/`..`/穿越/驱动器前缀（`workspace_error`）。

### 2.4 运行时日志

#### `list_runtime_logs(query?)` → RuntimeLogEntry[]
`query`: `{level?, source?, session?, search?, limit?}`；结果按时间倒序；内容已脱敏截断（8KB）。
字段：`{id, timestamp, level, source, session?, message, fields}`。

#### `clear_runtime_logs()` → void

#### `push_frontend_log(level, source?, session?, message, fields?)` → RuntimeLogEntry
前端日志汇入（脱敏统一处理）。

### 2.5 MCP 配置

#### `set_mcp_servers(servers?)` → object[]
保存 MCP 配置（校验 + 落盘 `pylon-mcp.json`，重启恢复）。`servers=null` = 清空。
返回：wire 序列化结果（官方 schema 形状，供回显）。校验失败 → `protocol_error`（>32 个、重复 identity、非法 transport/URL、NUL 等）。

### 2.6 宠物（状态机 v2）

#### `get_pet()` → PetView
```ts
{
  name, mood, stage, title, age_days,           // 注意：字段为 snake_case（v1 延续）
  xp, bond, happiness, energy,                  // 保留（happiness 为兼容字段）
  hunger, fun, loneliness,                       // v2 需求维度（0-100，时间戳衰减）
  traits: { activity, clinginess, greed, curiosity },  // 个性（出生随机）
  machine: "awake.idle" | "awake.interacting" | "awake.distress" | "asleep",
  crafting: boolean,                             // 捏朋友进行中
  born_at_ms, last_seen_day, first_chunk_at_ms,
  last_tick_at_ms, last_agent_mode?, last_agent_model?,
  recent_events: [...], pending_action?,         // 内部状态（前端一般只读 crafting）
  next_stage_xp, growth_progress,
  stats, memories, msg?                          // msg：待消费行为文案（含主动说话）
}
```
（12s 轮询：结算需求衰减 → 主动说话（饿/孤独/困/无聊/发呆/捏朋友完成），msg 单次消费后清空；睡眠中轮询**不唤醒**——真实唤醒靠 poke/feed/play）

#### `pet_action(action, value?)` → PetView
`action`: `"poke" | "feed" | "play" | "rename" | "daily" | "sleepy" | "nostalgia" | "restore"`。
v2 补充：`feed` 30s 内重复收益递减（100%→50%→25%→0）；`play` 消耗 energy -10、恢复 fun +25（60s bond 冷却）；`sleepy` 返回 `sleepy: boolean`。

### 2.7 权限审批（B9）

#### `approve_tool_call(request_id, option_id)` → void
应答挂起权限请求；`option_id` 必须是请求提供的选项（`allow_once`/`reject_once`/...）。未找到或非法 → `protocol_error`。

#### `set_approval_mode(mode)` → void
`mode`: `"bypass" | "auto" | "edit" | "default"`（bypass/auto 自动批准；edit/default 挂起询问）。

### 2.8 Git 只读（B5）

#### `git_status(source)` → GitStatusEntry[]
`{path, status, staged}`；status 为 porcelain 码（`" M"`/`"??"`/`"A "` 等）。非 git 仓库 → `git_error`。

#### `git_diff(source, path?, staged?)` → string
`staged=true` 看暂存区；`path` 必须相对且不穿越；输出 256KB 截断。

#### `git_history(source, limit?)` → GitCommit[]
`{hash, author, date(unix 秒), subject}`；limit 默认 50 / 上限 200。

### 2.9 网关（B10）

#### `gateway_status()` → object
`{ adapters: string[], routes: RouteBinding[], qq: {groupAllowFrom: string[]|null}, inject: {enabled, scenario?, sources, persist} }`。
`RouteBinding`: `{source, agentId, profileId, sessionKey, allowFrom?, reset?, idleMinutes?}`。

#### `reload_gateway()` → void
热重载 agents.yaml 的 `gateway` 段（路由/白名单/注入配置）；QQ 凭据仍启动生效。

## 3. 事件面（listen 名 + payload）

| 事件 | 触发时机 | payload |
|:--|:--|:--|
| `peri:user` | 用户消息发出（GUI 路径） | `{source, content, replay?: boolean, injectActivated?: string[]}`（replay=历史回放；injectActivated=B11 注入激活条目） |
| `peri:update` | agent 流式 session/update | `{sessionId, update, source}`——update 的 `sessionUpdate` 值：`agent_message_chunk` / `user_message_chunk` / `usage_update` / `tool_call` / `tool_call_update` / `session_info_update` / `config_option_update`；未知变体被白名单跳过 |
| `peri:done` | prompt 完成 | `{source, data}`（data=session/prompt 响应） |
| `peri:error` | prompt/连接错误 | `{source, error: string}` |
| `peri:agent-status` | 状态变化（连接/重连/崩溃） | 同 §4.5（status/lastError 为事件时值） |
| `pylon:runtime-log` | 新日志 | RuntimeLogEntry（§2.4） |
| `pylon:permission-request` | agent 请求工具权限（B9） | `{requestId: number, sessionId, toolCallId, title, prompt(脱敏摘要≤500字符), options: string[], requestedAt}`——前端应答调 `approve_tool_call` |

## 4. 数据结构

### 4.1 McpServerConfig
```ts
{
  id?: string; name?: string;
  transport: "stdio" | "sse" | "streamable-http" | "http";  // 空串自动推断
  enabled: boolean;                     // 默认 true
  command?: string;                     // stdio 必填
  args?: string[];
  env?: Record<string, string>;
  url?: string;                         // http 系必填
  headers?: Record<string, string>;
  oauth?: { enabled?, client_id?, client_secret?, scopes? };  // 仅表单校验，不进 wire
  disabled?: boolean;
}
```
注：`name` 必填（name→id 兜底）；env/headers 可能含 secret，后端会落盘但绝不进日志/输出。

### 4.2 SessionRow（load_sessions 行）
`{source, periId, persona, cwd, title, mode?, configOptions[], model, tokensIn, tokensOut, tokensTotal, contextSize}`

### 4.3 session_inspector 完整 DTO（B2）
```json
{
  "agent": { "id", "status", "lastError", "lastConnectedAt" },
  "summary": { "sessionCount", "activeCount", "tokensTotal", "tokensIn", "tokensOut" },
  "sessions": [{ "agentId", "source", "periId", "title", "model", "mode", "tokensIn", "tokensOut", "tokensTotal", "contextSize", "cwd" }],
  "workspace": { "<source>": { "path", "exists", "readable" } },
  "runtimes": [{ "agentId", "status", "lastError", "lastConnectedAt", "sessionCount", "activeCount", "tokensTotal" }]
}
```
summary/sessions 为**所有 runtime 全局合并**；`agentId` 区分来源。`activeCount` = 有 first prompt 的会话数（近似）。

### 4.4 agent_status DTO
```json
{
  "agentId", "agentName", "agent",            // agent 为展示兼容别名
  "status": "connecting|connected|reconnecting|crashed|disconnected|error",
  "transport", "cwd",
  "lastError", "recentError", "error",        // 三个为兼容别名，值相同
  "lastConnectedAt": string|null,
  "generation": number,                       // 客户端代际（会话路由）
  "active": boolean, "available": boolean, "crashed": boolean
}
```

## 5. 错误码全表（PylonError DTO `{code, message}`）

| code | 场景 |
|:--|:--|
| `acp_error` | ACP RPC/协议错误 |
| `agent_crashed` | agent 子进程崩溃（发送时检查） |
| `session_not_found` | source 无对应会话映射 |
| `no_active_agent` | 未配置/无 active agent |
| `unknown_agent` | 切换/连接未知 agent |
| `timeout` | 超时（保留） |
| `serialize_error` | 序列化失败 |
| `io_error` | 文件/IO 失败 |
| `protocol_error` | 参数/状态非法（上限、stale generation、非法 option 等） |
| `workspace_error` | 工作区路径安全/读取失败（detail 含原因码） |
| `prism_error` | Prism HTTP/配置错误（非 2xx 截断 4096） |
| `git_error` | git 不可用/非 git 仓库/命令失败/超时 |

## 6. 契约稳定性约定

- 命令名、参数名、错误码为**稳定契约**（前端按 code 分支，message 仅供展示）
- 事件 payload 为**可扩展**（新增字段不破坏；前端按存在性判断）
- 后端升级 `session_inspector`/`agent_status` 时保留 v1 兼容字段（`agent`/`summary`/`sessions` 顶层形状不变）
- secret 边界：env/headers/MCP oauth 不进任何事件、日志、错误 message
