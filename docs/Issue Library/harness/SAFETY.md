# 安全与失控防护

## 命令权限

允许：只读检索、构建、测试、格式检查、创建任务分支、普通 commit/push。

禁止自动执行：force push、hard reset、全仓 clean、删除远端分支、改 git 配置、发布、签名、上传凭据、修改用户 Hermes 配置、访问任务无关目录。

## 敏感信息

- secret 只通过环境或本地受保护存储注入。
- 测试 fixture 使用假值；日志和 handoff 必须脱敏。
- Gateway 加密实现任务不得把“可逆编码”当加密，也不得把密钥和密文放入同一普通配置。

## 失控停止条件

- diff 出现 scope 外文件。
- 依赖/contract 与 base 漂移。
- 测试产生不可解释的数据删除、网络写入或外部副作用。
- 同一修复策略失败两次且没有新增证据。
- 工作区包含不属于当前任务的未提交变更。

停止时不得清理或覆盖现场。创建 handoff，保存 `git status --short`、失败命令、最小日志和恢复建议。

## 审计

每个任务至少留下：任务卡、分支、commit、handoff、验证结果。聊天记录不是唯一审计材料。
