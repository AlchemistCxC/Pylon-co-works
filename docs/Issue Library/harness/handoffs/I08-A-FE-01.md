## 已完成

Views 只消费 touchedFiles 并统一 file/diff tab identity（AC-1，ISSUE-08 D-02/D-03/D-04）：

1. **Views 去 Git 化**（commit `51d638f`）：`ViewsPanel` 移除全部 Git 状态
   （gitStatus/activeDiff/onOpenDiff），props 收窄为 `{source, onOpenFile}`；
   只消费 `workspaceStore.touchedFiles[source]`，点击触碰文件行 → `onOpenFile(path)`
   进入普通文件视图。SCM 独占 Git 入口（`GitPanel` 只读，无任何写操作）。
2. **版本化 tab schema**（commit `9d2f545`）：`fileSheetState.ts` 新增
   `{version:2, tabs:[{path, mode:'file'|'diff', staged?}], activeKey}`；v1
   `openTabs:string[]` 在 `parseFileTabs` 内迁移为 file-mode tabs；损坏 JSON → 空
   （不清整个 persistence）。tab 单例 key = `${mode}:${path}`。
3. **统一 file/diff tab identity**（commit `29bc3cb`）：`FileTabBar` 按版本化 tab
   渲染（key 区分 path+mode，diff tab 带 mode/staged 标记）；`FileViewHost` 主区统一
   宿主（file → 发令栏+文件视图+状态栏；diff → 复用 `DiffView`/`DiffCard`；无 tab → 空态），
   承载编辑器瞬态（source 清空重置）；`FileSheetView` 以 openFileTab/openDiffTab/
   selectTab/closeTab 组合 action 写版本化 openTabs + activeFile；SCM 点击变更 →
   `openDiffTab`（diff-mode tab，**同路径 file/diff 不互相覆盖**，关闭/切换不串 mode）；
   v1 编解码 helpers（serializeOpenTabs/parseOpenTabs）与 `activeDiff` 本地态已删除。
