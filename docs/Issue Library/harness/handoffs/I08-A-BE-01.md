- 前置 I01-A-BE-01 已建立 `AgentContextKey` / `active_context_for_source` /
  `runtime_for_context` / `workspace_root_for_context` 解析链并删除 Git source 缺失时的
  active agent cwd fallback；本卡在其上补齐 **4 个非 Git workspace 命令共用解析函数

  1. `workspace_root_for_source_without_registered_runtime_errors`：active agent 已设但
     runtime 未注册 → `no_active_agent`，不静默成功。
  2. `workspace_root_for_source_rejects_unknown_source_without_cwd_fallback`：未知 source →
     `session_not_found`，不回退 active agent cwd。
  3. `workspace_root_for_source_rejects_runtime_instance_mismatch`：**AC-1 核心场景**——source
     属于 active agent A，调用方传入另一 agent B 的 runtime 实例 → `session_not_found`
     （消息含 `mismatch`），且绝不读取 B 的会话工作区。
  4. `workspace_root_for_source_resolves_active_session_cwd`：正常路径仍解析 active 会话 cwd
     （guard 不破坏正常操作）。
- 变异验证（guard 有牙齿）：临时禁用 `workspace_root_for_context` 的 runtime 实例
  `Arc::ptr_eq` 检查后，测试 3 立即变红（泄漏 `agent-b-workspace`）——证明测试能在
  guard 回退/绕行时捕获 AC-1 违规；随后恢复代码，全部转绿。恢复后 `session/mod.rs` 零 diff。
