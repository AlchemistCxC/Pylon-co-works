# I07-A-FE-02 handoff

## 交付结果

FileSheet 的 source-bound 异步请求现在统一携带 source/generation guard。切换 source、清除 source 或组件卸载后，旧请求的成功、失败和高亮回调均不能写入当前组件状态。

- `sourceRequestGuard.ts` 提供 source context 推进、请求 token 捕获与当前性判断。
- `FileTree` 保护根目录/子目录请求，并避免旧请求 finally 改写新 source 的 loading 状态。
- `WorkspaceSearchPanel` 切换 source 清空结果；同时以 request id 保证连续搜索只接受最新结果。
- `FileTabView` 保护文本读取、变更行计算、内容回传和异步代码高亮；source/path 变化及卸载会失效旧 token。
- `GitPanel`、`ViewsPanel`、`DiffView` 在已有 disposed 防护上补充 source/generation 校验。
