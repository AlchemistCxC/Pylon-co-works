## L3 验收步骤（交开阳测试，真实应用 + 真实工作区）

1. 打开真实 Tauri 应用 → File Sheet → 打开一个文本文件 → 点「编辑」→ 修改内容 →
   状态栏出现 `+N −M 未保存` 与「变更预览」面板 → 点「保存」→ 磁盘内容更新为编辑后
   内容，dirty 清除，「已保存」出现（AC-1 前半）。
2. 编辑期间用外部程序（如记事本/IDE）修改同一文件 → 回到应用点「保存」→ 拒绝并弹
   冲突条（不静默覆盖，dirty 保留）→ 点「覆盖保存」→ 用户编辑写盘、冲突解除；或点
   「重新加载」→ 本地编辑丢弃、内容回到磁盘版本（AC-1 后半）。
3. GBK 编码文件编辑保存后仍为 GBK（乱码回归检查）；UTF-8 BOM 文件保存后 BOM 保留；
   超过 256KB 文件「编辑」按钮禁用（truncated 只读）。
4. 编辑中让 Agent 通过工具修改同一文件（touchVersion 递增）→ 不静默覆盖用户编辑，
   冲突条出现；保存成功后锚点推进，后续 agent 修改正常刷新。
