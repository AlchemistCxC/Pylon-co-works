   `sheetLayoutSidebarCollapsedReactive.test.tsx`：折叠/展开两次切换，`.sidebar` 的 `collapsed`
   类即时翻转（修复前 RED 确认）。
3. **统一折叠宽度 token**（commit `1de8cd5`）：`themeCssSnapshot.ts` 导出
   `WORKSPACE_SIDEBAR_COLLAPSED_WIDTH = 42`（D-08 冻结），快照发出
   `--workspace-sidebar-collapsed-width`（Browser/File 内栏 FE-02 迁移消费点），
   `--titlebar-sidebar-width` 消费同一 token（折叠 = token 值）；`ThemeCssLayout` 增加
   `sidebarEnabled`——无侧栏时 titlebar 第一列固定 42px 控制区（方案 B，不占 250px 展开宽度）。
   `themeCssSnapshot.test.ts` 新增 3 断言（token=42 / titlebar 消费 token / 无侧栏固定 42px）。
4. **无 sidebar 不生成可操作折叠按钮**（commit `a8fd013`，AC-1）：`WorkspaceTitlebar` 接收
   `sidebarEnabled`，`disabled={!sidebarEnabled}`（title 标注"当前 Sheet 无侧栏"）；`App.tsx`
   从 active Sheet 的 registry 条目派生 `sidebarEnabled = sidebarMode !== 'none'`，同时喂给
   CSS snapshot 与 titlebar。新增 `workspaceTitlebarSidebarToggle.test.tsx`（3 断言：可操作 /
   禁用不触发 / 已折叠标注展开）。
