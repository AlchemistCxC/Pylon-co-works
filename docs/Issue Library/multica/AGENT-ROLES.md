## B 卡暂挂规则（已拍板）

B 卡（UX/FX，7 张：I06-B-UX-01、I07-B-UX-01、I08-B-FX-01、I09-B-FX-01、I10-B-FX-01、I12-B-UX-01、I13-B-FX-01）
**不导入天璇小队执行**，原因：

- B 卡的契约冻结逻辑（CONTRACT-FREEZE.md）与视觉所有权属于"角色 B"（另一个人及其 Agent）
- 天璇小队没有角色 B 的成员；强行派给天玑会破坏契约语义
- 处理：导入 Multica 时标记 `blocked-awaiting-role-B`，不派活；等角色 B 接入或用户重新拍板

## 契约与审查闸门

- 涉及共享契约的卡（I09-B-FX-01、I13-B-FX-01 的 contract 前置、任何 `contract_refs` 非空的卡）：
  必须先有 `contracts/active/` 的冻结版本才能实施——当前 contracts/ 目录尚未建立，相关卡保持 blocked
- 玉衡审查 = 进入 `in_review` 的前置条件；未审查不得宣称完成
- 最终 `done` 留人工（宫木云）确认——Agent 只能推到 `in_review`
