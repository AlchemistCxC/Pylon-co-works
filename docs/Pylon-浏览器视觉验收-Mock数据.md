# Pylon 浏览器视觉验收 Mock 数据

浏览器 Dev 模式默认启用 `visual` 场景。它只影响浏览器 Mock，不会进入 Tauri 桌面端，也不会读写真实 Agent 或工作目录。

## 启动

```powershell
npm run dev -- --host 127.0.0.1
```

首次验收或需要恢复基准数据时打开：

```text
http://127.0.0.1:5173/?demo-reset=1
```

完成重置后可去掉参数，日常使用 `http://127.0.0.1:5173/`。浏览器会保存交互状态，Mock 后端则在每次刷新时恢复预置工作区与插件包。

## 可选参数

| 参数 | 作用 |
|---|---|
| `demo-reset=1` | 重建 Mock 会话、消息缓存和 Sheet，不改主题设置 |
| `demo-permission=1` | 额外展示一条待审批权限请求 |
| `demo-scenario=standard` | 切换回 4 会话的轻量演示数据 |
| `demo-scenario=visual` | 显式启用完整视觉验收数据（Dev 默认） |

## 数据规模与验收入口

- 14 个会话：10 个视觉专项场景，加 4 个基础演示会话。
- 8 个工作区：覆盖多会话归属、空工作区、超长路径、不同 Agent 和工作区配置。
- 5 个 Agent：覆盖已连接、连接中、重连中、离线和错误状态。
- 4 个外置插件包：覆盖 Renderer、Feature、Skin、Service，以及不同版本、体积和文件数。
- FileSheet 文件树：包含应用、品牌资产、插件、领域模块、脚本、测试、文档与大量生成文件。
- Git 状态与历史：覆盖新增、修改、删除、重命名、未跟踪与多条提交历史。

会话专项场景：

| 会话 | 重点检查 |
|---|---|
| 渲染状态全景 | Markdown、思考、工具、代码、表格、引用和错误渲染 |
| 设置页视觉审计 | 设置排版、材质层级、字体和信息密度 |
| 窄窗口与超长标题 | 截断、Sheet 标签、侧栏和输入区响应式行为 |
| 长上下文架构评审 | 36 条消息的滚动节奏与渲染性能 |
| 并行任务与工具状态 | 21 个工具项及 7 种状态，包括未知状态兜底 |
| GUI 化渲染插件 | Renderer、Presentation Profile、Settings Page 文案 |
| 多语言排版 | 中文、英文、日文、阿拉伯文、Emoji 和超长单词 |
| 部署失败 → 恢复 | 错误、思考、回滚和成功状态的视觉权重 |
| 空白新会话 | 空消息状态 |
| 未绑定工作区的旧会话 | 未归类会话与 FileSheet 无根目录状态 |

插件页中的 Mock 外置包默认停用。这样可完整验收管理列表，同时避免浏览器尝试加载并不存在的演示插件脚本。
