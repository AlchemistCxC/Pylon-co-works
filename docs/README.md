## 维护规则

1. 文档中的命令、路径和能力必须能在当前仓库或发布脚本中找到依据。
2. 目标架构、施工计划和实验记录必须明确标注，并优先放在外部 Docs。
3. 同一事实只保留一个权威段落；其他文档使用链接，不复制整段说明。
4. 修改插件契约、存储格式、CLI 或用户可见行为时，同步更新对应章节并运行相关测试。
