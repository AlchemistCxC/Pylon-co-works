# Pylon 前端能力清单（后端暴露接口全集）

> 本文档是**后端暴露给前端的所有能力**的权威清单：命令（invoke）、事件（listen）、数据结构、错误码与调用约定。
> 事实源：`src-tauri/src/lib.rs` 的 `generate_handler!` 实注册 + 事件 emit 点（2026-08-01 对齐 main@a9be90c）。
> 若与源码冲突，以源码为准。版本历史见文末。

## 1. 调用约定

- **invoke**：`window.__TAURI__.core.invoke('命令名', { 参数, ... })`（Tauri v2，`withGlobalTauri: true`）
- **命名**：命令/参数 camelCase；**宠物 DTO 字段为 snake_case**（v1 延续，勿改）
- **错误**：所有命令失败返回 `{ code: string, message: string }`（见 §6 错误码表），成功按各命令返回类型
- **可选参数**：标 `?` 的字段传 `null` 或省略均可
- **安全边界**：secret（env/headers/oauth/token）永不出现在事件/日志/错误 message 中；Prism 写接口需 `PRISM_ADMIN_API_TOKEN`（后端已配，前端无需传）

## 3. 命令详情

### 3.1 会话与消息

#### `new_session(source, persona, cwd?, mcp_servers?)` → session/new 响应
创建会话（同 source 已存在则替换并 close 旧）。返回 agent 完整响应（`sessionId`/`modes`/`configOptions`）。上限 100 会话。

#### `send_message(source, content, persona, session_prompt?, attachments?, mcp_servers?)` → string（peri_id）
核心发送。行为链：
- 首条消息 persona 非空且不以 `/` 开头 → prompt 前拼 persona
- B11 注入开启时（默认开启）：发前调 Prism `/inject`，context 前置拼进 prompt；激活条目随 `peri:user.injectActivated` 返回
- 附件：≤8 个、≤10MB/个（图片→image block；文本/未知→text block）
- 返回 `peri_id`（会话标识）

#### `set_mode(source, mode)` / `set_config_option(source, key, value)` → void / agent 响应
`key="model"` 时按 agent 配置分叉（Hermes 系走 `session/set_model`，Peri 走 `set_config_option`——后端自动处理）。

#### `close_session(source)` / `cancel_prompt(source)` → void
close：cancel 在途 prompt → `session/close`（agent 不支持时降级本地清理）→ 应答挂起权限为 Cancelled。cancel：fire-and-forget + settle 30s + 应答权限 Cancelled。

#### `load_sessions()` → SessionRow[] / `session_inspector()` → 全局聚合（见 §4.3）
#### `load_persisted_session(source, peri_id, cwd?, mcp_servers?)` / `list_persisted_sessions()`
重放历史：replay 事件经 `peri:user`/`peri:update`（带 `replay: true`）回放。

#### `export_session(peri_id, format, output_path)` → void
`format`: `"markdown" | "json"`；拒绝覆盖已存在文件；内容经 secret 脱敏（rawInput/rawOutput/prompt/persona/headers/env/authorization/token/secret 全删）。

### 3.2 Agent 生命周期

| 命令 | 返回 | 说明 |
|:--|:--|:--|
| `list_agents()` | AgentSummary[] | `{id, name, transport, available, active, cwd}` |
| `switch_agent(name)` | void | 目标懒启动；旧 agent 停 dispatcher + kill 进程，状态置 Disconnected |
| `reconnect_agent()` | void | 重连 active（清空会话映射） |
| `agent_status()` | 见 §4.4 | 含 generation（会话路由代际） |
| `reload_agents(config_path?)` | void | 热加载 agents.yaml；不可移除 active agent |
| `validate_agents()` | object | `{valid, defaultAgentId, agents}`（不启动进程） |

### 3.3 工作区（只读）

| 命令 | 参数 | 返回 |
|:--|:--|:--|
| `get_workspace_root` | source | `{source, path, exists, readable}` |
| `list_workspace_entries` | source, relative_path?, include_hidden? | `[{name, relative_path, kind, size, modified_at?, hidden, expandable}]`（忽略 .git/node_modules/dist 等；1000 条上限） |
| `read_workspace_text` | source, relative_path, max_bytes? | `{relative_path, content, bytes_read, total_bytes, truncated, encoding}`（默认 256KB/最大 1MB；NUL/非 UTF-8 → 错误） |

路径安全：拒绝绝对路径/`..`/穿越/驱动器前缀（`workspace_error`）。

|:--|:--|

| `clear_runtime_logs()` | 清空 |
| `push_frontend_log(level, source?, session?, message, fields?)` | 前端日志汇入（统一脱敏） |

### 3.5 MCP 配置

`set_mcp_servers(servers?)` → wire 序列化结果（object[]）
保存 MCP 配置（校验 + 落盘 `pylon-mcp.json`，重启恢复）。`servers=null` 清空。校验失败 → `protocol_error`（>32 个/重复 identity/非法 transport/URL/NUL）。disabled server 不参与去重（可作"排除冲突"途径）。

### 3.6 宠物（状态机 v2）

#### `get_pet()` → PetView（12s 轮询建议）
```ts
{
  name, mood, stage, title, age_days,            // snake_case（v1 延续）
  xp, bond, happiness, energy,                   // happiness 为兼容字段
  hunger, fun, loneliness,                       // v2 需求（0-100，时间戳衰减）
  traits: { activity, clinginess, greed, curiosity },  // 个性（出生随机）
  machine: "awake.idle" | "awake.interacting" | "awake.distress" | "asleep",
  crafting: boolean,                             // 捏朋友进行中
  born_at_ms, last_seen_day, first_chunk_at_ms, last_tick_at_ms,
  last_agent_mode?, last_agent_model?, recent_events: [...], pending_action?,
  next_stage_xp, growth_progress, stats, memories, msg?
}
```
轮询行为：结算需求衰减 → 主动说话（饿/孤独/困/无聊/发呆/捏朋友完成）→ `msg` 单次消费后清空。**睡眠中轮询不唤醒**（真实唤醒靠互动）。

#### `pet_action(action, value?)` → PetView
动作：`poke` / `feed` / `play` / `rename` / `daily` / `sleepy` / `nostalgia` / `restore`。
- `feed`：30s 内重复收益递减（100%→50%→25%→0）
- `play`：energy -10、fun +25×好奇心、60s bond 冷却
- `rename`/`restore` 需 `value`；`sleepy` 返回额外 `sleepy: boolean`

### 3.7 权限审批（B9）

| 命令 | 说明 |
|:--|:--|
| `approve_tool_call(request_id, option_id)` | 应答挂起权限请求（option_id 必须是请求提供的选项） |
| `set_approval_mode(mode)` | `"bypass" \| "auto"` 自动批准；`"edit" \| "default"` 挂起询问 |

挂起请求经 `pylon:permission-request` 事件到达（含脱敏 prompt 摘要 ≤500 字符）；超时 300s 默认拒绝；cancel/close 应答 Cancelled。

### 3.8 Git 只读（B5）

|:--|:--|:--|
| `git_status` | source | `[{path, status, staged}]`（porcelain 码） |
| `git_diff` | source, path?, staged? | string（256KB 截断；path 必须相对） |
| `git_history` | source, limit? | `[{hash, author, date(unix秒), subject}]`（默认 50/上限 200） |

非 git 仓库 → `git_error`；超时 10s 自动杀进程。

## 6. 错误码全表

| code | 场景 |
|:--|:--|
| `acp_error` | ACP RPC/协议错误 |
| `agent_crashed` | agent 子进程崩溃 |
| `session_not_found` | source 无会话映射 |
| `no_active_agent` | 无 active agent |
| `unknown_agent` | 未知 agent |
| `timeout` | 超时（保留） |
| `serialize_error` / `io_error` | 序列化 / IO |
| `protocol_error` | 参数/状态非法 |
| `workspace_error` | 路径安全/读取失败 |
| `prism_error` | Prism HTTP/配置错误（body 截断 4096） |
| `git_error` | git 不可用/非仓库/超时 |

## 7. 契约稳定性

- **稳定**：命令名、参数名、错误码（前端按 code 分支，message 仅供展示）
- **可扩展**：事件 payload 新增字段不破坏（按存在性判断）
- **兼容**：`session_inspector`/`agent_status` 保留 v1 顶层字段；宠物新增字段渐进消费
- **Secret 边界**：env/headers/oauth/token 不进任何事件、日志、错误 message、导出
