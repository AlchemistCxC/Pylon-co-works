# ⌁ 终端蟹 — ASCII 宠物视觉规范

基于 `ascii.co.uk` 蜘蛛蟹（作者 tre）改编。8 行，表情只改眼睛+嘴+腿。

## 帧定义

## 动画参数

| 情绪 | 帧间隔 | 备注 |
|:--|:--|:--|
| idle | 1000ms | A→B→A 循环 |
| curious | 600ms | 单帧（暂不眨眼） |
| excited | 350ms | A→B→A，B 帧右上飘 ✦ |
| sleepy | 1500ms | 单帧，整体 y+1px 下沉 |
| error | 400ms | A→B→A，B 帧右上冒 💢 |
| happy | 500ms | A→B→A，B 帧右上飘 ♡ |

## 后端 API

| invoke | 参数 | 返回 |
|:--|:--|:--|
| `get_pet` | — | `{mood, happiness, messages, first_chunk_at_ms}` |
| `pet_action` | `action: "poke"\|"feed"\|"daily"\|"sleepy"` | 更新后的 PetState |

后端自动在 send_message 流程中更新 mood，前端只需：
1. 初始化时调 `get_pet`
2. 每 5s 轮询 `get_pet`（或监听 `peri:done`/`peri:error` 事件同步更新）
3. 点击调 `pet_action("poke")`
4. 根据 `mood` 字段选帧渲染
