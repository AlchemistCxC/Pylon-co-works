# Pylon 宠物文案库（状态机 v2）

> 配套：`docs/宠物状态机v2设计.md` · 风格基调：微光/像素/代码世界里的光之生物（延续现有"微栖/微光种"世界观）
> 机制：每个场景一个**文案池**（3-5 条），选取规则见 §1；`[个性]` 标记的条目仅在对应 trait 高时进入池

---

## 1. 文案池机制

- **选取**：同池随机不重复（滚动索引，避免连续同一条）
- **冷却**：紧急需求文案（饿/孤独/困）不冷却；普通事件文案 30s 冷却（防刷屏）
- **个性修饰**：高 trait 宠物从"普通池 + 个性池"合并后抽取（个性条目概率加权）
- **风格红线**：不说人话、不拟人过度（保持"光之生物"感）、不评价用户能力

## 10. 文案与数值的绑定约定

- 所有"需求危机"文案在对应需求恢复后**自动解除**（下一条文案回归普通池）
- 紧急需求文案（HUNGRY/LONELY/TIRED/BORED）**无视冷却**但同 key 30s 内不重复
- 个性池只在 trait ≥ 70 时启用（0-100）
- 记忆条目使用 §8 模板（`{占位}` 由状态机填充），与记忆系统 §10（设计书）一致
