### 2.2 运行时架构

后端由以下部分组成：

1. `src-tauri/src/acp.rs`
   - 启动 ACP 子进程。
   - stdin/stdout JSON-RPC transport。
   - request pending map、response oneshot、notification broadcast。
   - initialize、session new/load/prompt/close/list/mode/config/cancel。
   - child RAII 清理、timeout/cancel 收敛、附件 ContentBlock。
2. `src-tauri/src/lib.rs`
   - Tauri commands 与前端 events。
   - `source -> SessionInfo(periId)` 映射。
   - Agent 两阶段切换、client generation、notification dispatcher。
   - 会话导出、Pet 状态和应用启动降级。
3. `src-tauri/src/agent_config.rs`
   - 编译期默认 Agent registry。
   - 外部 YAML runtime reload。
   - 相对 exe/cwd 的明确路径基准。
4. `agents.yaml`
   - 默认 Agent 定义；命令名通过 PATH 查找。

## 3. 协议真值与不变量

ACP 真值只能来自：

```text
F:\A-I\Agent\Peri\peri-tui\src\acp_stdio\
F:\A-I\Agent\Peri\peri-tui\src\acp_server\
F:\A-I\Agent\Peri\acp-hub\
```

已确认协议：

- `initialize` 使用 `clientCapabilities`。
- `session/set_mode` 使用 `modeId`。
- `session/new` 返回 `sessionId`、`modes`、`configOptions`。
- `session/load` 在 response 前 replay history。
- notification variant 使用 snake_case。
- `session/cancel` 是 notification。
- `session/close` 是 request。
- `session/set_config_option.value` 使用 tagged `ValueId`。

三层 ID：

| 层 | 字段 | 用途 |
|---|---|---|
| 前端 | `Session.id` | Zustand 本地实体 ID |
| Pylon 后端 | `source` | Tauri command key、后端 sessions map key |
| Peri ACP | `periId` / `sessionId` | Agent 远端会话 ID |

禁止将三者互换。

核心生命周期不变量：

- 同一 source prompt 串行，不同 source 可并行。
- prompt 等待不持有全局 session creation 或 Agent lifecycle lock。
- timeout 向正确 periId 发 cancel，并继续等待最终 response 最多 30 秒。
- pending 在序列化、写入、response、RPC error、timeout、EOF 路径收敛。
- initialize 失败必须 kill + wait child。
- Agent 切换顺序：新 client connect+initialize → 原子 swap → generation +1 → 清 sessions → 新 dispatcher → 关闭旧 client。
- generation 变化后，旧 Agent 的 new/load/prompt/mode/config/cancel/close/list/export response 不得提交。
- dispatcher 绑定 generation，旧 receiver 不得向当前 UI 派发迟发通知。
- replay response 是完成边界，不使用固定 sleep。

## 6. 已知限制与待验证修复

1. Windows GNU/Tauri test binary 当前无法进入 harness：`0xc0000139`。需要在可运行 harness 的环境执行已有 Rust tests。
2. ACP notification 不带 turn/request identity。timeout 取消收敛期间的旧 chunk 只能通过 session/generation 边界隔离，无法精确归属到 turn。
3. `prompt_locks` map 未清理，长期创建大量 source 可能增长。
4. 附件路径来自前端字符串。已有数量、大小、MIME 和读取限制，但完整安全边界仍需要 Tauri scoped capability。
5. Peri 对未知 session 的合法 `end_turn` 与真实零输出成功可能同形；后端依赖本地映射和 generation 防止向未知 session 发送。
6. `agent_status`/`peri:agent-status` 的前端状态页接入仍需按《前端API接口文档》落实。
7. Pet 状态目前仅内存保存，应用重启丢失；这不是当前 Bug 清单中的阻塞项。
