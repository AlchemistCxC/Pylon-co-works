## 当前已实施、待测试

### BUG-P0-02

- 根因：React 会话切换后，旧 messages 与新 render sessionId 可能在持久化 effect 中短暂错配。
- 实现摘要：增加消息 owner/session guard，按真实 Session.id 持久化；切换时清理旧 view owner；提取纯函数并新增回归脚本验证 A 的消息不能写入 B。
- 主要文件：`src/components/chat/ChatView.tsx`、`src/components/chat/messagePersistence.ts`、`scripts/test-message-persistence.mts`
- 自动验证：`node --experimental-strip-types scripts/test-message-persistence.mts` exit 0；`npm run build` exit 0，3296 modules；`git diff --check` exit 0。
- 未验证：真实 Tauri A→B→A→B 与重启恢复。

### BUG-P0-03

- 根因：事件曾由当前可见 ChatView 按 `sessionRef.current` 过滤，后台 source 的 chunk/tool/done/error 被永久丢弃；生成态也是单一 source。
- 实现摘要：消息仓库按 source 分区，所有事件先路由到所属 source；仅当前 source 同步 React 展示；generating 改为 source 集合，done/error 只清理自身；提取纯状态函数并增加多会话回归脚本。
- 主要文件：`ChatView.tsx`、`InputBar.tsx`、`Settings.tsx`、`store.ts`、`sessionEventState.ts`、`scripts/test-session-event-state.mts`
- 自动验证：`test-session-event-state.mts`、`test-message-persistence.mts`、`test-replay-state.mts` 均 exit 0；`npm run build` exit 0，3297 modules；`git diff --check` exit 0。
- 未验证：真实 Tauri 下 A/B 同时生成、切换、取消、done/error。
- 结构风险：listener 仍随唯一常驻 ChatView 挂载，尚未迁移为独立应用级 controller；当前 App 不卸载 ChatView，因此不影响已知路由场景。

### BUG-P0-04

- 根因：localStorage 先恢复，Peri replay 再追加；replay user event 被当实时 prompt，且成功 replay 后旧缓存未同步清理，可能在后续失败恢复时再次出现陈旧历史。
- 实现摘要：独立 replay buffer；load response 为边界；成功使用 replay，失败保留缓存；replay 不启动 generating；成功 replay 后以 replay 结果覆盖 localStorage，空 replay 删除旧缓存。
- 主要文件：`ChatView.tsx`、`replayState.ts`、`scripts/test-replay-state.mts`
- 自动验证：`test-replay-state.mts`、`test-session-event-state.mts`、`test-message-persistence.mts` 均 exit 0；`npm run build` exit 0，3297 modules；`git diff --check` exit 0。
- 未验证：真实 Tauri + Peri persisted session。
- 后端依赖：`periReplay` 与完整 load response 已存在于当前后端工作区，后端提交状态由后端 Coder 管理。

### BUG-P1-07

- 根因：`/model` 只修改 active Profile 的 model，没有调用当前 Peri session；ModelWidget 虽调用后端，但与命令重复实现且错误被静默吞掉。
- 实现摘要：提取统一 `setSessionModel(source, model)`；命令与 ModelWidget 共用同一路径；乐观更新 `sessionConfig[source]`，失败回滚旧值并在输入栏显示错误。
- 主要文件：`InputBar.tsx`、`ModelWidget.tsx`、`sessionModel.ts`、`sessionModelState.ts`、`scripts/test-session-model.mts`
- 自动验证：`test-session-model.mts` exit 0；`npm run build` exit 0，3299 modules；`git diff --check` exit 0。
- 未验证：真实 ACP 请求抓包、后端失败 UI、A/B 分 source 切换。

### BUG-P1-10

- 根因：Zustand partialize 主动排除了 `profiles`，但保留 `activeProfileId`，重启后 Profile 编辑丢失且 active ID 可能指向不存在的 Profile。
- 实现摘要：profiles 与 activeProfileId 进入同一个 `pylon-theme` schema；增加 version/migrate 与 hydrate 归一化；悬空 ID 回退首个有效 Profile；ProfileEditor 统一使用 store action 保存。
- 主要文件：`store.ts`、`ProfileEditor.tsx`、`profilePersistence.ts`、`scripts/test-profile-persistence.mts`
- 自动验证：`test-profile-persistence.mts` exit 0；`npm run build` exit 0，3300 modules；`git diff --check` exit 0。
- 未验证：真实应用重启、损坏 localStorage、session.profileId persona 运行时链路。

### BUG-P2-01

- 根因：`send_message` 的 try/catch 之后无条件执行 `setValue('')` 与 `setAttached([])`，失败也会丢失待重试内容。
- 实现摘要：提取发送事务；只有 invoke 成功才更新 lastMsg、清空输入/附件和清除错误；失败保留原状态并显示错误。
- 主要文件：`InputBar.tsx`、`sendTransaction.ts`、`scripts/test-send-transaction.mts`
- 自动验证：`test-send-transaction.mts` exit 0；`npm run build` exit 0，3301 modules；`git diff --check` exit 0。
- 未验证：真实 Agent 断开、附件保留、恢复后重试。

### BUG-P2-02

- 根因：mode 存在单一 `liveMode`，A/B 会话共享；命令与 ModeWidget 先改全局值，后端失败不回滚且错误被吞掉。
- 实现摘要：增加 `sessionModes[source]`；命令与 ModeWidget 共用 `setSessionMode`；乐观更新按 source 分区并失败回滚；new/load/config update 从后端真值同步对应 source。
- 主要文件：`ModeWidget.tsx`、`InputBar.tsx`、`ChatView.tsx`、`store.ts`、`sessionMode.ts`、`sessionModeState.ts`、`scripts/test-session-mode.mts`
- 自动验证：`test-session-mode.mts` exit 0；`npm run build` exit 0，3303 modules；`git diff --check` exit 0。
- 未验证：真实 A/B mode 切换、ACP 请求抓包、失败 UI、config update 回写。
